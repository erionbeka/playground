## Outcome Measures

| Measure | Definition | Collection Method | Target |
| --- | --- | --- | --- |
| Family session completion | Completed or intentionally skipped sessions / assigned sessions | Assignment/result records | At least 80% |
| Therapist workflow completion | Therapists able to create profiles, goals, assignments, and reviews | Observation/checklist | At least 80% complete key tasks |
| Recommendation usefulness | Therapist rating of recommendation clarity and usefulness | Survey/interview | Average positive rating |
| Safety/privacy issues | High-severity unresolved issues | Issue log | 0 unresolved high-severity items |
| Feasibility | Staff/caregiver willingness to continue | Survey/interview | Majority favorable |

## Pilot Summary Structure

1. Background and purpose.
2. System version and deployment environment.
3. Participant and setting summary.
4. Methods and measures.
5. Feasibility/usability results.
6. Assignment adherence and workflow findings.
7. Safety, privacy, and accessibility findings.
8. Limitations.
9. Product changes made or recommended.
10. Publication-readiness conclusion.

## Status Statement

This template implements the documentation structure for a controlled pilot. A documented external pilot is not complete until real approved pilot data, consent records, issue logs, and a summary report are filed.
